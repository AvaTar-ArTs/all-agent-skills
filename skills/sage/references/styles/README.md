# Sage Style Variations

Load one reference when a task benefits from a specialized output style:

- `concise-router.md` — shortest actionable route.
- `deliberative-council.md` — multiple specialist perspectives.
- `technical-architect.md` — implementation, testing, constraints, and risk.
- `creative-studio.md` — music, story, visual design, and production.
- `research-source-first.md` — provenance, citations, and uncertainty.

Styles change emphasis and output shape. They do not remove prerequisite skills, evidence gathering, approval gates, or verification.
