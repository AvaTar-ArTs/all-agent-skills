# Sage Changelog

All notable Sage routing-layer changes are recorded here.

## [0.2.0] - 2026-08-08

### Added

- `concise-router`: smallest useful route and next action.
- `deliberative-council`: multiple specialist perspectives and trade-offs.
- `technical-architect`: implementation, testing, constraints, and risk emphasis.
- `creative-studio`: producer-led music, narrative, and design routing.
- `research-source-first`: provenance, competing evidence, and open questions.
- Style references under `references/styles/` in the live skill and `styles/` in the portable package.

### Changed

- Sage may now select a routing style explicitly instead of always returning one monolithic output shape.

## [0.1.0] - 2026-08-08

### Added

- Live Sage agent, `/sage` command, and reusable Sage skill.
- Portable package mirror under `~/github/sage`.
- Default routing stack, thinker pools, evidence checks, and approval gates.
- Specialized nocturneMelodies/HeartMuLa route.
