# all-agent-skills

Research and governance for a portable, auditable agent-skills ecosystem.

This repository is intentionally initialized with governance and research
artifacts first. Private local skill and agent bodies are not copied here by
default. They should be imported only after provenance, licensing, secrets,
host compatibility, and publication scope have been reviewed.

## Repository goals

- Define one capability authority model.
- Distinguish canonical, projected, project-local, archived, cached, system,
  experimental, and compatibility material.
- Make skill and agent discovery reproducible.
- Keep host projections healthy without creating competing writable sources.
- Separate instructions from external app/MCP authority.
- Prevent secrets, histories, credentials, and private session data from being
  indexed or published.

## Current status

The repository began empty on 2026-08-18. The initial commit contains the
research basis and registry schema only. A later import of selected public or
user-approved capability content should be performed as a separate, reviewed
change.
